# Data Science Days 2027
Data Science Days is a hackathon-style event that brings together people who develop, maintain and support SciLifeLab’s data workflows, software and computational infrastructure in a hands-on environment. Starting with the registration and leading up to the event, participants will be invited to join and shape cross-platform projects for groups of 6-10 people with support from peers with experience across the following broad themes:
1. **Reproducible workflows & software development**, e.g. shared workflow templates, Nextflow/Snakemake best practices, CI/CD, containerisation, testing, documentation and publication of pipelines.
1. **AI & automation for data science**, e.g. AI coding agents, shared agent instructions and skills, LLM-assisted analysis, local versus cloud AI, validation and security
1. **Data interoperability & metadata harmonisation**, e.g. common metadata templates, sample/project identifiers, FAIR data practices, interoperability between platforms and data submission workflows
1. **Shared computational infrastructure & technical solutions**, e.g. HPC and cloud workflows, secure data transfer, storage, shared code repositories, technical debt and reusable infrastructure components
1. **Cross-platform data integration & scientific applications**, covering topics such as combining datasets across platforms, multi-omics integration, interoperable analysis pipelines, shared analytical tools and cross-platform proof-of-concept projects

Contribute an idea or collaborate on a topic:\

## Examples of ideas that could be developed into breakout topics:
* **Shared software development practices across SciLifeLab**\
  Compare development guidelines and established practices from the Data Centre, NBIS and other platforms. Identify useful approaches to code quality, testing, documentation, security and collaboration that could be adopted more widely.\
  *Possible result:* A common RSE practices checklist and a shortlist of improvements to existing development guidelines.
* **AI agents for discovering SciLifeLab tools, services and expertise**\
  Explore how AI agents could help researchers or infrastructure staff find relevant SciLifeLab services, analytical tools, training materials or expertise. Develop a small demonstrator using structured information or selected service interfaces.\
  *Possible result:* A prototype assistant, MCP wrapper or documented agent workflow for one well-defined service discovery task.
* **Tracing data from sample preparation to scientific results**  
  Explore how sample preparation, instrument runs, processing steps, analysis results and quality-control information can be linked and documented. Use a realistic workflow to identify missing information and opportunities for shared provenance practices.  
  *Possible result:* An example end-to-end provenance record or data model connecting samples, processing steps, analytical outputs and reports.
